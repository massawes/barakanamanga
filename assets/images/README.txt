Place your real branding images in this folder using these exact filenames
so the site picks them up automatically:

    school-logo.png     - shown in the navbar (recommended: square, ~100x100px)
    school-building.jpg - optional, for future use on the About page
    hero.jpg            - optional, for future use as a hero background

If school-logo.png is missing, the navbar simply hides the logo image and
shows the school name text only — nothing breaks.
